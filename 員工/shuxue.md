## 考卷格式（照佩穎老師去年的期末卷）

- 抬頭：`桃園市八德國小115學年度第1學期四年級數學領域期末評量試卷`（小考就寫「第○單元小考」）。
- 大題順序和題型參考去年的卷子：
  是非題 → 選擇題 → 用直式算算看 → 填填看 → 把做法用算式記下來（應用題）→ 連連看 → 畫畫看。
  依這次的單元內容挑，**至少三種題型、含素養導向題**，不一定每種都要有。
- 每個大題標「每題○分，共○分」，**總分剛好 100**。
- 卷末最後一行：`【寫完請記得檢查喔!】`
- 四年級**不用加注音**（學校規定一至三年級才加）。
- 原稿寫在 `題庫/`，檔名例如 `題庫/數學_四上_第6-10單元_期末考.md`、`題庫/數學_四上_第6單元_小考.md`。
  開頭的基本資料寫 `類型: 考卷`、`年級: 四年級`、`時間: 40 分鐘`、`總分: 100`，其他寫法照 `範例/考卷寫法範例.md`。

### 數學專用的寫法（排版工具看得懂）

- **分數**寫成 `{{3/5}}`，帶分數寫 `{{2 3/5}}`，排出來是上下疊的分數。不要寫成 3/5 或「五分之三」（題目文字本來就要寫國字的除外）。
- **直式計算、寫算式的空間**：在那一題的答案、解析下面另起一行寫 `<留白 6>`（數字是留幾行，直式乘除法約 6～8 行，應用題約 4～5 行）。
- 乘除號用 `×`、`÷`，等號 `＝`，減號 `－`，加號 `＋`；餘數寫「…」（例如 `34÷9＝3…7`）。
- **圖**：題目說「下圖」就一定要有圖。數線、刻度尺、方格、圖形規律這類簡單的圖，用 Python 畫成 PNG 存在 `題庫/圖/`，在題目裡用 `![說明](圖/檔名.png)` 插入（沒有 matplotlib 就先 `pip install matplotlib`）。畫不出來的，先寫 `【圖：要畫什麼】` 交給老師，並在回覆裡列出來。

## 數學出題原則

1. **範圍以課本為準**：只考這冊課本教過的概念和數字範圍。例如分數只到同分母、小數只到二位小數、長度到公里公尺公分。超出就不出。
2. **每題自己用 Python 算一次答案**（不要心算），答案卷寫的一定是算過的數字。除法題確認有沒有餘數、應用題確認答案合理（人數不能是小數、錢是整數元）。
3. **單位要寫清楚**：題目和答案都要有單位，換算題寫明要換成什麼單位。
4. **一題只考一個概念**，題意只能有一種讀法。應用題要寫清楚「每人」「平分」「還剩」這類關鍵字。
5. **不照抄**課本、習作、教師手冊的題目（學校檢核表要求原創）：可以參考題型和難度，數字和情境一定要換。也不要和習作的題目只差一個數字。
6. **難度**：雙向細目表勾「適中」，大部分是基本題，少數挑戰題。素養題（生活情境、要讀圖表或資料）**最多 10 分**。
7. **各單元平均分配**：例如考 5 個單元，每單元約 20 分。
8. **選擇題**：四個選項、只有一個正確，錯的選項用學生常見的錯誤（例如假分數換帶分數時分子分母寫反、小數對位錯）。答案 ①②③④ 分散。
9. **是非題**：○ 和 × 數量差不多，錯在一個關鍵細節。
10. 份量：**40 分鐘寫得完**；B4 雙面最多兩張。

## 雙向細目表（另外填成學校的 Word 檔）

1. 原稿最上面的註解（`<!-- -->`）先寫一份簡單的細目表，自己核對用。
2. 另外寫一個 JSON 檔，和原稿同名加「_細目表」，例如 `題庫/數學_四上_第6-10單元_期末考_細目表.json`。格式在 `tools/fill_spec.py` 最上面的說明：
   - 年級「四」、類別「期末」、領域「數學」、時間「40」、難易度「適中」。
   - 範圍：第六單元至第十單元，課本頁碼從課本 PDF 確認（不確定先問老師，不要猜）。
   - 素養題寫在第幾大題第幾小題。
   - 每個單元一組，每種題型一列，記憶／理解／高層次（應用、分析、綜合、評鑑、素養題）各寫 `[題數, 配分]`。
   - 單元名稱照課本：第六單元分數、第七單元數量關係、第八單元整數四則、第九單元小數、第十單元長度。
3. 執行 `python tools/fill_spec.py 題庫/…_細目表.json`。它會把學校範本（`佩穎數學檔案/114學年度定期評量試卷檢核表與雙向細目表.docx`）填好，輸出到 `成品/考卷/…_檢核表與雙向細目表.docx`，並檢查合計是不是 100 分、高層次有沒有超過 10 分。要 PDF 時再跑 `python tools/to_pdf.py 成品/考卷/…_檢核表與雙向細目表.docx`。
4. 檢核表的勾選欄（□）留給老師自己勾。範本裡「請命題教師於○年○月○日前送教學組」那行是學校去年的日期，提醒老師改。
