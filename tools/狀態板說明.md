# 辦公室狀態板（辦公室狀態.js）詳細說明

> 只有要改公佈欄（board.progress／current／notes），或在 Code 分頁工作要自己更新狀態時才需要讀這份。


老師用瀏覽器開 `辦公室.html` 看大家在做什麼。畫面每 3 秒讀一次 `辦公室狀態.js`：

```js
window.OFFICE_STATE = {
  "updated": "2026-11-13 10:30",
  "staff": {
    "beike": {"status": "idle", "task": "", "since": ""}
    // status: idle（閒著）、working（工作中）、waiting（等老師確認）、done（做完）
  },
  "board": {
    "current": "五上 第2單元",             // 黑板上大字寫的「現在進度」
    "progress": [                          // 黑板上的進度表
      {"unit": "五上 2-1 臺灣的地形", "備課": "完成", "學習單": "審題中", "考卷": ""}
    ],
    "notes": ["週五前交第2單元小考"]       // 黑板角落的便條，最多 5 張
  },
  "log": [{"time": "…", "who": "beike", "text": "…"}]   // 最新的在最前面，最多 20 筆
}
```

**省額度：** 每讀或改一次這個檔都要多跑步驟，每一步都會重讀整段對話。所以只在下面列的時機改它。

### 什麼時候更新

**從指令台來的工作（訊息最後有「指令台附註」）：`staff` 和 `log` 由指令台自動更新，你不要改。**
指令台開工時會把你改成 `working`；做完時看你回覆的最後一行：
- 需要老師看或做決定：寫「【待確認】要確認什麼」（20 字以內），會變成 `waiting`。
- 其他情況：寫「【完成】做完了什麼」（20 字以內），會變成 `done`。
- 有【交接】時，【交接】那行放在【完成】的上一行。

不管從哪裡來，下面這些要自己改（一件工作最多改一次，做完時一起改）：
- 某個單元的備課、學習單、考卷狀態有變：更新 `board.progress` 那一列（沒有就加一列）。狀態用「備課中／完成／出題中／審題中／待修改／已排版」。
- 老師說要換教的單元：更新 `board.current`。
- 老師交代有期限的事、或事情做完要拿掉：更新 `board.notes`。

**從 Code 分頁或手機來的工作（沒有「指令台附註」）**：沒有指令台幫忙，開工和做完時照上面的格式自己改自己的 `staff` 那一筆，並在 `log` 最前面加一筆（老師的指示記成 `"who": "teacher"`），更新 `updated`。

改之前先重讀一次（別人可能剛改過），只改需要改的欄位，改完確認仍是合法的 JSON（前面的 `window.OFFICE_STATE = ` 和結尾的 `;` 要留著）。
